# Saas Portfolio

## Collection of online software tools that are useful for South Africans.

![zatools logo](/assets/logo.png)

Available tools:

1. [z83 form fill and generate tool](https://z83.zatools.co.za), optimised for mobile.
    Useful tool that allows you to create and fill a government z83 form (government job application form), sign it and generate the filled form as pdf. Also does validation to ensure that form was filled correctly.
